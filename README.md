# Automotive Manufacturing Analytics Dashboard

## Project Overview

This project analyzes automotive manufacturing and supplier performance using Power BI. The dashboard helps monitor supplier delivery performance, defect rates, average lead time, total orders, procurement cost, and supplier distribution across warehouses and part categories.

## Key KPIs

- **Total Orders:** 150
- **Total Suppliers:** 150
- **Average Lead Time:** 2,293 (as displayed on the dashboard; verify the measure and unit)
- **Defect Rate:** 406.39% (as displayed on the dashboard; verify the DAX calculation)
- **On-Time Delivery:** 4,200% (as displayed on the dashboard; verify the percentage calculation)
- **Total Procurement Cost:** 36M

## Dashboard Analysis

The dashboard provides insights into:

- On-Time Delivery Percentage by Part Name
- Defect Rate by Material
- Average Lead Time by Material
- Total Orders by Supplier Name
- Total Procurement Cost by Warehouse
- Total Suppliers by Part Category
- Supplier, Warehouse, Region, Quality Status, Material, Part Name, and On-Time Delivery filters

## Tools Used

- Power BI
- DAX
- Power Query
- Microsoft Excel / CSV

## Key Insights

- Delivery performance varies across different automotive parts.
- Defect rates differ by material, helping identify materials that may require quality improvement.
- Average lead time varies by material, which can help identify potential delivery bottlenecks.
- Order distribution across suppliers helps monitor supplier workload.
- Procurement costs vary across warehouse locations.
- Part category analysis helps understand supplier distribution across automotive components.

## Business Recommendations

- Monitor suppliers with frequent delivery delays.
- Investigate materials with higher defect rates and improve quality checks.
- Review long lead times to identify opportunities to improve delivery efficiency.
- Compare warehouse procurement costs to identify potential cost-saving opportunities.
- Regularly monitor supplier performance using the dashboard filters.
